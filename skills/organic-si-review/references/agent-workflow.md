# 子智能体分工与调度

## 1. 建检查队列

主审以本轮用户要求为准，建立只读的来源清单和检查队列。来源记录角色、版次、路径、页数、SHA-256、范围和排除理由。候选关联单独标注待核。检查单元是可追溯的对象与动作，例如「化合物 X 的 ¹H NMR 报告与谱图对照」或「图 2b 的结构与 SI 表征图对照」。只给「第 30–60 页」不足以说明每项检查，须同时给化合物范围、检查类型和覆盖分母。跨页或跨文件比较分给明确的主责人员。

先标出可并行项目。需要共同索引时，主审生成页码、化合物、样品批号、历史编号、谱图和图版之间的初步对照，附来源与匹配依据。把它作为导航，关键匹配回原件确认。不要把暂定匹配作为硬条件或令全部分支停工。发现索引疑点时交给主审更新，通知受影响分支重查。

## 2. 首轮和后续批次

| 角色 | 分配材料 | 独立任务和交接 |
| --- | --- | --- |
| 主审 | 用户要求、全部纳入来源的索引、计算材料及投稿附件 | 控制范围、拆队列、协调跨件对照、核关键 DFT 和正文主张、裁决冲突、汇总并发布。计算量大时移交 DFT，主审保留结论审读。 |
| A · NMR 与 HRMS | SI 表征段、核磁谱图、已有仪器导出、离子式 | 对照文字与谱图、计算氢积分和离子质量、区分溶剂/杂质/重叠。交回可复算表、未看清谱图与疑似身份错配。公式与结构疑点交给 B 核证。 |
| B · IR、编号与图文 | SI 对应段、IR、旧编号表、正文图及图注 | 建样品到化合物和谱图的映射，核峰表、正文结构/编号/立体图示、图表交叉引用。返还带原件锚点的映射和未匹配项。手性色谱工作量小时可随本支分配，但单列覆盖。 |
| C · 方法、文字与引用 | 通法、个例、表格、目录、图注与参考文献 | 查规模、投料、浓度、当量、时间、产率和方法可复现性。统一量纲并逐处保留原值。查文字格式与引用，和 B 对照图文编号，向 A/B 报可能影响样品身份的冲突。 |
| 按需 · DFT / HPLC 或 SFC / 晶体 | 仅给本专题纳入的材料 | DFT 复算和对图。色谱核样品和积分。CIF 按已安装的晶体审阅技能，或标注可执行的最低审查。每个专题有独立队列和覆盖状态。 |
| 第二轮 · 独立复核 | 原件、定位和待判定问题所需的最少上下文 | 核高影响条目、跨来源冲突、旧项关闭和否定性结论的依据，找反例、版本差异或其他合理解释。补查时记录真正看过的内容。 |
| 交付验证 · 按需 | 报告、底账、批注副本与源件对照 | 有多份批注副本或复杂网页交互时，可在空闲槽位请一人独立验收。由其回传可重现的问题、定位和实测覆盖，主审统一修正和重验。 |

总并发按当前会话容量和用户约束。四个槽位含主审时，通常是主审加三条并行分支。后续专题、复核或交付验证复用空闲槽位。并发不足时按高风险、长耗时和依赖关系先后排队。某一类材料占大部分工作量时，可按不重叠的化合物区间或资料类型分给多名同专长人员。主审统一边界和去重规则。定点核对用主审或按需加一名专题智能体。不要为凑角色启动空任务、无限重试或创建新的用户聊天。

例如，只有两名子智能体可用时，先并行派谱学和结构/图文，主审查方法与 DFT。若只有一名子智能体，给它证据密集且可独立推进的一支，主审处理其余优先项。首支回收后，用空出的槽补查或复核主审负责的条目。首轮完成一支即可处理其可独立复核的项目，依赖样品映射的条目等对应证据齐备再合并。

主审负责派发，子智能体默认不再次派发，避免抢占槽位。专项确实需要内部分工时，由主审安排空闲槽位。只有实际执行了角色和复核，才在报告中如此记载。无可用子智能体时，将同一检查队列顺序执行，高影响条目另行回读并记录为主审复核。

## 3. 派发与回收

每名智能体收到一张独立工单。需要隔离上下文时，用不继承聊天的方式创建任务，并明确给本技能引用文件和必要输入。禁止把上轮结论、作者预期或其他分支的结论随手发给盲审人。

```text
任务模式和职责
来源 ID、版次、允许读取的路径和相关页
明确排除及不得访问的材料
检查单元、分母及与其他分支的交接点
应先读的技能参考文件
分支工作目录（原件和共用索引只读）
回传候选问题、逐项覆盖、计算/索引和阻塞项
```

子智能体用本分支前缀给候选项临时编号。每条回传要说明对象、检查单元、观测值和比较值，并附单位和计算依据。给出每个来源 ID、可辨锚点、取证方式及适用的 PDF 物理页。注明判断、前提、影响、证据状态和核对动作。无发现也要回传覆盖和实际检查方式。遇到缺页、读图失败、版本或样品冲突，立即回传可定位的已完成部分和阻塞项。可以继续检查不依赖它的单元。文件只写自己目录。澄清索引、补查某个对象或复算时优先找原负责人，注明新批次或被替代的回传。独立复核选未做过该项的人，盲审另用无历史上下文的任务。主审写最终底账和批注。

## 4. 合并、反查与旧项

1. **核对交接。** 汇合结构与公式、内部样品号和化合物号、正文图和 SI、通法与个例、计算表和图。一个根因在多个地方重复时保留一个问题和多个锚点。同一页上不同根因分别列项。
2. **找能推翻结论的证据。** 先核版本、样品、单位、分母、图轴或参考态等。尽可能让未参与原判定的人只凭原件作判断，再对照候选结论。真实盲审不给预期结构、待验证的方向、前轮结论或含答案的报告。上下文含这些信息时记录为非盲交叉复核。确定错误须有原件支持。异议保留各自证据、主审裁决依据和仍缺什么，不能靠多数票或直接沿用旧报告。
3. **追旧项。** 主审给新版初审分支发中性的范围与原件。在新版独立审阅后，才把历史问题和对应旧锚点分给合适负责人比对。按根因及实体映射，避免新版重编号或移页造成误判。证据不足时按无法核实。明确排除时按本轮排除。检查每个旧 ID 均有唯一状态，新出现的独立问题另给新 ID。
4. **遇到中断。** 先保留已回收证据，重派未覆盖部分或由主审补查。可纠正的路径、版本或解析问题先修正再重试。确无原件、权限或可用读图能力时记录具体缺口。用检查队列与覆盖表对账后再交付，不从文件数量或返回状态推定完成。
