# 有机化学 SI 审阅

以作者能回到原件、判断问题并修订为目标。默认用中文说明，保留原有英文、化学式、单位和术语。按当前授权读取材料，只在新的独立审阅目录写输出。批注另存，禁止覆盖源件或旧报告。对未发表材料只用用户授权的处理环境，禁止自行上传、外发或以未发表化合物、结构、谱图或内部编号作为外部查询。外部参考仅在需要时用已公开的标识查询，并区分查到的公开证据与本地观测。若用户要求完全本地处理，采用符合该限制的本地工具，明确哪些判断因处理环境受限而未完成。

## 定范围与分工

1. 清点输入、版次和用途，给当前原件、对照件与上轮底账分配来源 ID。对 PDF 建立物理页与印刷页索引，并记录源件初始 SHA-256。多个候选版本有实质歧义时，先查可独立处理的材料，再确认目标。以用户本轮要求定范围，明确排除项、缺件和边界。在覆盖表保留所需但缺证据的检查，先派发可执行部分。
2. 区分三种任务。**定点核对**只检查用户指定问题及直接关联证据。**全面审阅**给正文、SI、谱图等实际纳入的材料分配检查单元。**新版全面复查**独立检查新版，并逐条判定旧 ID 的状态。若用户只要求销项，只检查给定旧项和必要关联。
3. 大任务先向用户简述分工、检查项和范围，再并行执行。主审负责范围、来源和化合物关联表，通常自己核 DFT、关键图文结论和投稿附件。首轮常用三路为 **NMR/HRMS**、**IR/编号/配图**、**实验方法/文字/交叉引用**。按材料调整，手性色谱或晶体只在本轮范围内且有对应证据时分派。小任务按必要性启动子智能体。按 [子智能体分工与调度](references/agent-workflow.md) 分派、交接和复核，按 [专项核对](references/chemistry-checks.md) 选择实际适用的检查。没有子智能体时分阶段顺序执行，并如实记录独立复核状态。

## 查证与交付

- 先确认化合物、样品、批次和文档之间的关联，再合并结论。对数值尽可能用可复算的本地工具，记录输入、算法、单位、分母和舍入。文本提取、OCR 和图像筛查只作相应层级的证据。涉及结构、箭头、谱图或字形的实质问题必须返回原页目视确认。关联或位置未确认的项保留为待核。
- 分别标记影响程度和证据状态。发现冲突时并列原文、位置和推断前提，给作者可执行的核对动作。影响结构、身份、关键数值或主要结论的条目，以及相互冲突的结论，由主审回读原件并优先安排独立反查。任何缺失、抽查、读图失败或工具未执行都必须在覆盖中可见。
- 主审统一去重、分配 ID 并生成报告和可定位批注。定点任务可直接交付带锚点的结论。全面任务默认交付可搜索、可勾选的本地 HTML 报告、结构化底账和适用的 PDF 批注副本。需要打印或用户要求时另存 PDF 报告。根据 [报告与验证](references/deliverables.md) 核验来源哈希、覆盖、批注和交互。最终列出优先处理项、未覆盖项和输出位置。
